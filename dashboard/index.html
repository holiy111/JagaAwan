📘 Langkah Cepat Remediasi untuk UMKM

Panduan cepat jika bucket Anda terdeteksi berisiko Tinggi atau Sedang:

1
Ubah ke Private Bucket

Masuk ke Supabase/GCP Console, buka konfigurasi bucket foto, dan matikan akses Public agar data tidak bisa diakses publik langsung.

2
Gunakan Signed URL

Gunakan endpoint /signed_url di backend JagaAwan untuk memberikan tautan berbatas waktu (misal 5 menit) untuk katalog produk.

3
Atur File Limits

Terapkan file_size_limit (misal maks 5MB) dan batasi MIME type hanya untuk gambar (JPEG/PNG/WEBP) guna mencegah malware.
